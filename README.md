# StatikPro-Website

Willkommen auf dem offiziellen Repository der **StatikPro Engineering**-Website. Dieses Projekt repräsentiert unsere Dienstleistungen im Bereich Tragwerksplanung, Statikberechnungen und Planerstellung.

## 🚀 Funktionen und Features
- Übersicht über unsere Dienstleistungen
- Kontaktformular zur direkten Anfrage
- Galerie von Projektreferenzen

## 🛠️ Installation und lokale Nutzung
Falls du die Website lokal bearbeiten oder testen möchtest:

```bash
git clone https://github.com/benutzername/statikpro-website.git
cd statikpro-website
```

Öffne die Dateien mit einem lokalen Webserver oder direkt im Browser.
