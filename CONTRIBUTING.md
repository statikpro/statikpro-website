# Beitragsrichtlinien für StatikPro Engineering

Vielen Dank für dein Interesse, zu **StatikPro Engineering** beizutragen! Wir schätzen jede Unterstützung und möchten sicherstellen, dass der Beitrag reibungslos verläuft.

## 🚀 Wie du beitragen kannst

- **Fehler melden:** Öffne ein Issue und beschreibe das Problem klar und präzise.
- **Neue Funktionen vorschlagen:** Stelle sicher, dass dein Vorschlag gut durchdacht ist und einen Mehrwert bietet.
- **Code beitragen:** Erstelle einen Pull-Request (PR) mit einer klaren Beschreibung.
- **Dokumentation verbessern:** Korrekturen und Ergänzungen sind immer willkommen.

## 🛠️ Lokale Entwicklung

1. Forke das Repository.
2. Klone es lokal:
   ```bash
   git clone https://github.com/benutzername/statikpro-website.git
   ```
3. Erstelle einen neuen Branch für deine Änderungen:
   ```bash
   git checkout -b mein-beitrag
   ```
4. Führe deine Änderungen durch und committe sie:
   ```bash
   git commit -m "Beschreibung der Änderung"
   ```
5. Push deinen Branch:
   ```bash
   git push origin mein-beitrag
   ```
6. Erstelle einen Pull-Request.

## ✅ Pull-Request-Richtlinien

- Stelle sicher, dass dein Code getestet wurde.
- Beschreibe deine Änderungen klar im Pull-Request.
- Halte dich an bestehende Code-Stil-Richtlinien.
